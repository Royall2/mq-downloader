              🚀 نشر مجاني HTTPS
            
            GitHub Pages + BotFather
          

          
مساعد الاستضافة المجانية ورفع GitHub

          

            خطوات عملية سريعة من الجوال لرفع تطبيق MQ downloader مجاناً والحصول على رابط آمن جاهز لربطه ببوتك في تليجرام.
          

        


        
        

          

            

              1
              تصدير ملف index.html
            

            HTML Single File
          

          

            نزّل ملف index.html مباشرة على هاتفك أو انسخ كامل الكود لوضعه في مستودع GitHub.
          

          

            

            
          

        


        
        

          

            

              2
              نشر تلقائي عبر GitHub Actions
            

            
          

          

            أنشئ في مستودعك المسار .github/workflows/deploy.yml والصق الكود التالي لنشر index.html تلقائياً على GitHub Pages مع كل تعديل:
          

          
name: Deploy MQ downloader to GitHub Pages

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Pages
        uses: actions/configure-pages@v5
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: "."
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
